# 🎨 Polotno Editor Templates - Quick Overview

## 📚 What's Inside

**7 ready-to-use presentation templates** for educational content creation!

Located in: `/assets/templates/`

## 🚀 Quick Start

1. **Open the Editor** (in `/Editor/index.html` or via Teacher dashboard)
2. **Click**: File → Open
3. **Select**: Any template from `/assets/templates/`
4. **Edit**: Replace text, add images, customize colors
5. **Save**: File → Save (or Export as PDF/PNG)

## 📋 Available Templates

### 🔬 Science Lesson
**File**: `science-lesson.json`
