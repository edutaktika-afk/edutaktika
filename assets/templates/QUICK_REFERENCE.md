# Quick Reference Guide - Polotno Templates

## 📋 Template Cheat Sheet

### Science Lesson (`science-lesson.json`)
```
Pages: 4 (Cover → Objectives → Content → Summary)
Colors: Blue (#3498db), Green (#2ecc71)
Use for: Science lessons, experiments, concepts
Edit: Replace [Topic], update objectives, add content
```

### Math Lesson (`math-lesson.json`)
```
Pages: 4 (Cover → Formula → Example → Practice)
Colors: Purple (#8e44ad), Yellow (#f1c40f)
Use for: Math lessons, formulas, problem-solving
Edit: Add formula, worked example, practice problems
```

### English Essay (`english-essay.json`)
```
Pages: 5 (Cover → Intro → Body1 → Body2 → Conclusion)
Colors: Purple (#9b59b6), White
Use for: Essay writing, structured writing guides
Edit: Replace prompts, add essay content
```

### Book Report (`book-report.json`)
```
Pages: 4 (Cover → Summary → Characters → Opinion)
Colors: Green (#27ae60), White
Use for: Book reports, literature reviews
Edit: Book title, author, summary, characters
```

### Quiz/Assessment (`quiz-assessment.json`)
```
Pages: 2+ (Cover → Questions)
Colors: Red (#e74c3c)
Use for: Quizzes, tests, assessments
Edit: Add questions, answers, duplicate for more
```

### Blank Presentation (`blank-presentation.json`)
```
Pages: 2 (Title → Content)
Colors: Blue (#3498db)
Use for: Any subject, custom content
Edit: Everything - it's your canvas!
```

## ⚡ Quick Actions

### Loading a Template
```
1. Open Editor
2. File → Open
3. Select template.json
4. Click Open
```

### Common Edits
| Task | Action |
|------|--------|
| Edit text | Click on text |
| Change color | Select → Color picker |
| Add image | Drag & drop OR Upload panel |
| Add page | Pages panel → + button |
| Duplicate page | Right-click page → Duplicate |
| Delete element | Select → Delete key |

### Saving Your Work
```
File → Save → [your-lesson-name].json
```

### Exporting
```
File → Export → Choose format (PDF/PNG/JPG)
```

## 📐 Standard Sizes

- **Canvas**: 1920 × 1080 pixels (16:9 ratio)
- **Title Text**: 96-130px
- **Header Text**: 64-80px
- **Body Text**: 36-48px
- **Small Text**: 28-32px

## 🚀 Workflow Examples

### Creating a Science Lesson (5 minutes)
```
1. Open science-lesson.json
2. Page 1: Change title to "Cell Structure"
3. Page 2: Update 3 learning objectives
4. Page 3: Add cell diagram + bullet points
5. Page 4: Add key takeaway
6. Save as "science-cell-structure-g6.json"
```

### Creating a Math Quiz (10 minutes)
```
1. Open quiz-assessment.json
2. Page 1: Set subject "Algebra" + time "30 min"
3. Page 2: Write Question 1 + 4 options
4. Duplicate Page 2 for Question 2-10
5. Update each question
6. Save as "math-algebra-quiz-g6.json"
```

### Creating a Book Report (8 minutes)
```
1. Open book-report.json
2. Page 1: Add book title + author + your name
3. Page 2: Write 3-4 sentence summary
4. Page 3: Describe 2-3 main characters
5. Page 4: Add your opinion + rating
6. Save as "book-report-[bookname].json"
```

## 🎯 Pro Tips

### For Best Results
✅ Start with the template closest to your needs  
✅ Keep color scheme consistent (2-3 colors max)  
✅ Use high-resolution images (min 800px wide)  
✅ Test on actual display before class  
✅ Save often (Ctrl+S)

### Common Mistakes to Avoid
❌ Too much text on one slide  
❌ Tiny fonts (below 28px)  
❌ Low-contrast colors  
❌ Forgetting to update date/grade level  
❌ Not testing before presenting

## 📁 File Organization

Recommended naming convention:
```
[subject]-[topic]-[grade]-[date].json

Examples:
science-photosynthesis-g6-2025-01.json
math-fractions-g5-quiz.json
english-essay-structure-g6.json
```
